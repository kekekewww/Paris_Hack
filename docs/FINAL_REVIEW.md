### FR-01／P2：明確否定被誤判為肯定事件（已修復）

位置：`backend/app/ai/providers.py` 的 `_mention_state()`。

獨立重現原結果：

| 輸入 | 原錯誤結果 | 修復後應有結果 |
|---|---|---|
| 我住院了，手術沒有做 | `surgery: yes` | `surgery: no` |

### FR-02／P2：前端對話逾時短於後端處理預算（已修復）

位置：`src/services/api-claim-service.js` 的建構參數與 `sendMessage()`。

原前端對話沿用一般請求 15 秒逾時，外部 adapter 預算為 20 秒、後端對話路由為 45 秒。獨立離線實測以 16 秒後成功回覆的注入 fetch 執行預設 `sendMessage()`，於 **15,012ms** 收到 `TIMEOUT`。實際服務可能已完成並保存對話，前端卻提示失敗，使用者重試便可能產生重複呼叫。

修復加入獨立的 `messageTimeout = 50000`，驗證設定值並由 `sendMessage()` 使用；一般請求與分析的預算維持各自設定。主代理回報專項單元測試經失敗確認後修復通過；獨立 reviewer 已確認程式及注入短預算的回歸案例存在。

### FR-03／P2：混合 PDF 的清晰度提醒指向錯頁，且被標成辨識依據（已修復）

位置：`backend/app/ocr/analyzer.py` 的 `_extract()`／品質 finding，以及 `src/components.js` 的 `analysisResult()`。

獨立 reviewer 以記憶體內 PDF 重現：第 1 頁為完整合成文字 PDF，第 2 頁為模糊掃描圖，並將 `_ocr_lines` 替換成立即拋錯的函式以保證不執行模型。原結果正確保留 `pdf_text` 與 `uncertain`，但清晰度 finding 及框線都標為第 1 頁；實際被跳過的是第 2 頁。UI 又僅依整份結果的 `quality_precheck` provider 決定文案，導致混合結果把品質提示描述成辨識位置與「官方依據」。

修復在內部保留 `rejected_pages`，為每個跳過頁面建立對應頁碼的清晰度 finding／框線；該提示的辨識信心為 0，不捏造已讀欄位。UI 依 `image_quality` finding 類型提供「官方表單參考」與人工提示區說明；混合文件保留實際使用的文字／OCR provider，並明示部分內容未可靠辨識。整份僅通過清晰度預檢時，顯示未執行 OCR，不顯示文字信心或宣稱未見缺漏。

主代理回報第 1 頁文字加第 2 頁模糊掃描、兩頁均模糊的頁碼斷言均先確認失敗，再修復通過；完整 OCR **28 項通過（29.44 秒）**、完整後端 **190 項通過（31.90 秒）**。前端混合結果案例亦先確認失敗，再修復；全部前端單元測試 **24 項通過**。Reviewer 已唯讀確認修補與上述斷言存在，未重新執行模型或瀏覽器；這些測試結果由主代理提供。

此修補不等於已找出先前偶發 `OCR_UNAVAILABLE` 的根因。先前 API 27 項中的平板模糊文件曾失敗；加入安全診斷後 18 次實際 HTTP 輪替未重現，只能記錄未重現。低品質文件現在依既有啟發式門檻停止文字辨識，不能稱為修好了上游模型故障，也不能稱門檻來自官方規範。安全 logger 僅記錄例外類型與程式檔名／函式／行號，不記錄例外內容、區域變數或原始文件；本輪未見新增隱私洩漏。

- 外部模型僅能選取本次官方索引的完整段落；伺服器驗證段落與引用，不允許模型改案件、文件狀態、資格或給付結果。`grounded_rules` 是本機規則／檢索，不能稱為生成式 LLM。
- 真實外部 LLM 請求仍未驗證。使用者已要求金鑰稍後設定；離線 adapter 測試與設定齊備都不能代替真實驗收，相關項目維持 **BLOCKED**。
- Docker 設定與本機測試不證明容器實際啟動或公開 HTTPS 可用；映像、容器、外部主機、DNS／TLS 與部署授權須各自留下證據。本文不宣稱公開部署完成。
- 案件寫入鎖與速率限制屬程序內狀態。現有預設單一 worker；多 worker／多副本須重新處理並行寫入與集中限流，不能直接視為已支援。反向代理亦可能共用限流來源 IP。
- OCR 有檔案大小、頁數、圖片像素及處理時間檢查，但已啟動的 CPU 工作不保證在取消時立即終止；這不等同惡意文件處理的完整程序隔離。辨識只涵蓋指定欄位，簽名與其他文件仍須人工覆核。
- 原始上傳檔與擷取全文不保存至案件庫，擷取值有遮罩；使用者對話、檔名與其他結構化資料仍可能敏感。Cookie owner 隔離與短期保留不是正式會員身分驗證或正式保險服務資安驗收。
- 官方索引是查核時間點的資料，執行期不自動監測來源異動；複雜否定、混合事件及未涵蓋語句仍須人工確認。條件式項目不可因資訊不足就推定免附。

Compose 模型變數、環境範本及舊文件敘述的同步由主代理安排；最終階段狀態以更新後的任務、驗收報告與實際測試紀錄為準。
